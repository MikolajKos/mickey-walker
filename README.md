# Mickey Walker

Personal blog of Mikołaj Kosiorek, written as Mickey Walker.

The site is built around three paths:

- **To Experience** – travel, awareness and personal growth
- **To Expand** – programming, electronics and engineering projects
- **To Express** – music I create and the stories behind it

## Status

Work in progress. The site is being built step by step, starting with the home page and the three paths.

## Stack

- Next.js (App Router), React, TypeScript
- CSS Modules
- MDX for blog posts
- Hosted on Vercel

## Planned

- Post pages with location, tech tags or track details, depending on the path
- Audio player for music posts
- Comments with moderation
- About sections for each path

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
